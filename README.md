EcoMind - уникальный сайт про природу и её сохранение.

Технологии: HTML5, CSS3, Vanilla JavaScript.

Чтобы запустить этот проект локально, выполните следующие шаги:
1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/temastraik/EcoMind
    ```
2.  **Перейдите в директорию проекта:**
    ```bash
    cd EcoMind
    ```
3.  **Запустите проект:**
    Так как это статические файлы, вы можете просто открыть файл `index.html` в вашем браузере.

Функционал:

- Калькуляторы, рассчитывающие вред природе;

- Галерея природы;

- Познавательная информация, которая поможет каждому бережно относить к природе.
